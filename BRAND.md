# heymedy brand guide

Read this before creating any visual asset (feature images, diagrams, illustrations). Every image must match these specs.

## Brand essence

heymedy is a warm, trustworthy AI health companion — not a cold medical tool. The visual identity is organic, human, and calm. Think: thoughtful friend, not hospital waiting room.

## Colors

| Name | Hex | Usage |
|---|---|---|
| Cream (primary background) | `#F9F6F1` | Default page/image background |
| Cream dark | `#EDE8E1` | Borders, dividers, subtle sections |
| Dark brown (text) | `#3B3228` | Primary text, headings |
| Brown light | `#A09686` | Secondary text, captions |
| Brown muted | `#C4BAB0` | Tertiary text, labels |
| Terracotta (accent) | `#C2785C` | Accent words, highlights, CTAs |
| Terracotta hover | `#B06A4E` | Hover states only |

**Accent usage rule:** Use terracotta sparingly — ideally on ONE word or element per image. It's a highlight color, not a primary surface color.

## Typography

- **Headings / display type**: Instrument Serif (Google Fonts)
  - Use italic variant for accent/emphasis words
  - Tight line-height (1.05-1.1)
  - Can be very large (60-120px in feature images)
- **Body / UI type**: DM Sans (Google Fonts)
  - Regular (400) for body
  - Medium (500) for labels
  - Semibold (600) for emphasis

**Typography pattern (from heymedy.com hero):**
> "Your health, *organized*." — "Your health," in dark brown serif, "organized" in italic terracotta serif

## Feature image specs

- **Dimensions**: 1200×630px (OpenGraph/Twitter card standard)
- **Background**: Cream `#F9F6F1`
- **Layout**: Left-aligned text, generous padding (80-120px), no centered symmetry
- **Title**: Instrument Serif, dark brown `#3B3228`, ~60-80px
  - Wrap onto 2-3 lines for visual weight
  - Highlight 1-2 key words in italic terracotta `#C2785C`
- **Optional decoration**: soft blurred circles in terracotta at 10-20% opacity, positioned in corners
- **No text outside the headline** — no subtitles, no "heymedy" logo on the image itself (Ghost adds the site name on social cards separately)

## Illustrations / imagery

- Mascot: coral/salmon blob character (used sparingly, not on every image)
- Line art: organic curves, 1.5-2px stroke weight, dark brown
- No photographs of medical settings, people, or generic stock imagery
- No 3D renders, no gradients filling large areas
- If using icons: simple outlined (1.5px stroke), rounded corners, terracotta accent

## Tone/mood words

**Yes**: warm, calm, organic, handwritten-feeling, thoughtful, open, soft
**No**: clinical, corporate, futuristic, high-tech, urgent, aggressive

## Anti-patterns — do not do these

- Blue/purple "AI" gradients
- Stock photos (doctors, stethoscopes, pill bottles, lab beakers)
- Dark mode backgrounds (the brand lives in warm light mode)
- Heavy shadows, glows, or neon effects
- Stark white `#FFFFFF` backgrounds (always cream)
- Sans-serif display type (DM Sans is for body, not hero text)
- Multiple accent colors on one image
- Emoji in graphics
- 3D illustrations, isometric art, or flat corporate "Corporate Memphis" style
